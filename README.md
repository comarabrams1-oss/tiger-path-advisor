# Tiger Path Advisor

Course planning and degree progress for Benedict College students. The app uses a demo sign-in and imported course offerings.

## Course information and interview practice

Ask Tiger Path uses plain-language course summaries from the [Benedict College Catalogue 2025–2026](https://benedict.edu/wp-content/uploads/2026/01/2025-2026-Benedict-College-Master-Catalogue-010826.pdf). Course content is independent of the imported section snapshots and the app's degree rules.

Readiness uses the six questions from [Kamya's Interview Prep app](https://studio.code.org/projects/applab/3acef4f8-55d8-49b3-8dfc-2cda26f8b24e). The same Gemini server endpoint rates practice answers. The latest feedback for each question and the milestone checklist are saved locally by demo profile.
